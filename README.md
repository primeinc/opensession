# OpenSession

Web viewer for OpenCode sessions.

```
  ╭─────────────────────────────────────╮
  │                                     │
  │   OpenSession Viewer                │
  │   http://localhost:3456             │
  │                                     │
  │   Press Ctrl+C to stop              │
  │                                     │
  ╰─────────────────────────────────────╯
```

## Installation

You can run OpenSession directly using `npx`:

```bash
npx opensession
```

Or install it globally:

```bash
npm install -g opensession
opensession
```

## Development

```bash
git clone https://github.com/ryanvogel/opensession.git
cd opensession
npm install
npm run dev
```
